这次主要解决升级 DSH 后，data-agent 在插件列表里显示“启动失败”、数据模式无法使用的问题。

- 修复插件启动时的 `standingKeyFor is not a function` 报错，让数据模式能在新版 DSH 中正常加载。
- 修复 Web 新建或切换会话时，数据库工作台入口可能找不到当前会话的问题，并更新数据库图标和预设选择控件的接入方式。
- 修复数据目录生成 AI 业务说明时，与新版模型接口不兼容的问题。
- 升级时保留用户改过的预设和名称；只自动更新能够确认是插件原版的旧预设。

**版本要求：本版适配 DSH `0.1.7-rc.1`。如果还在使用旧版 DSH，请先保留原来的插件版本，等升级 DSH 后再安装本版。**

安装或升级 Web 插件：

```sh
dsh plugin --profile web add @yejiming/dsh-data-agent@0.2.0 --registry=https://registry.npmjs.org/
```

安装完成后，退出正在运行的 DSH，再执行 `dsh web`，并刷新浏览器页面。只更新项目源码，不会替换 Web profile 里已经安装的旧插件。

发布前已通过类型检查、构建和 443 项测试，另有 3 项外部数据库测试因环境条件跳过。打包后的插件已验证 SQLite 查询、预设切换、卸载重载和会话恢复；也已在本机 Web 中确认插件与数据模式正常加载。本次没有进行真实模型 API、外部数据库或浏览器交互验收。
